## Getting started

This is an UI app for manage banking with user


## How to run

1. Navigate UI app folder
```
cd banking-ui
```

2. Install dependency
```
pnpm install
```

3. Create `.env` based on `.env.example` and set values:
```
VITE_CLERK_PUBLISHABLE_KEY=
```

4. Run app

```
pnpm run dev
```
